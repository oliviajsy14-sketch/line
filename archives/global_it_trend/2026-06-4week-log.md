## 처리 기준

- Global IT Trend Sheet Query만 사용했다.
- Query 순서는 규칙 문서의 Global IT Trend Sheet Query 순서를 유지했다.
- 출력 컬럼은 `대분류`, `Query / Service`, `Korean Title`, `Check Box`, `URL`만 사용했다.
- 신규 기사 Check Box는 모두 `FALSE`로 입력했다.
- 기간 내 확인 기사가 없는 Query는 `n/a`로 입력했다.
- Naver / LINE / LY Corporation 단독 기사는 제외 기준에 따라 입력하지 않았다.
- 1차/2차 생성본에서 누락이 많았다는 피드백을 반영해 전체 Global Query 134개를 다시 기준으로 두고, Google Query 계열과 The Bridge / ASCII STARTUP 등 Asia Big Tech 보완 소스를 추가 확인했다.
- Notion 기사는 AI Agent Query에만 남기고 Tech Crunch Startup 중복 배치는 제거했다.
- The Bridge는 본문 직접 fetch가 403으로 차단되었지만, 검색 결과의 기사 URL·제목·날짜 단서가 date_range와 Query에 부합해 최종 URL을 입력하고 로그에 제한을 명시했다.
